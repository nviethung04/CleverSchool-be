📝 HTML Fundamentals

What is HTML?

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It describes the structure of web content.

Key Concepts:

  • Elements - Building blocks of HTML
  • Tags - Define elements
  • Attributes - Provide additional information
  • Semantic HTML - Meaningful structure
<!DOCTYPE html> <html> <head> <title>My Page</title> </head> <body> <h1>Hello World!</h1> <p>Welcome to web development.</p> </body> </html>

🎨 CSS Styling

Cascading Style Sheets

CSS is used to style and layout web pages. It controls the visual presentation of HTML elements.

CSS Features:

  • Selectors - Target specific elements
  • Properties - Define styles
  • Flexbox & Grid - Modern layouts
  • Responsive Design - Mobile-friendly
.container { display: flex; justify-content: center; align-items: center; background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); min-height: 100vh; } .button { padding: 12px 24px; border-radius: 8px; background: #667eea; color: white; border: none; cursor: pointer; }

⚡ JavaScript Programming

Adding Interactivity

JavaScript is a programming language that enables interactive web pages and dynamic content.

JavaScript Capabilities:

  • DOM Manipulation - Change page content
  • Event Handling - Respond to user actions
  • AJAX - Load data dynamically
  • Frameworks - React, Vue, Angular
// Simple JavaScript example document.addEventListener('DOMContentLoaded', function() { const button = document.querySelector('.btn'); const counter = document.querySelector('.counter'); let count = 0; button.addEventListener('click', function() { count++; counter.textContent = count; }); });
